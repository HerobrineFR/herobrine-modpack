## Installation

La vidéo ci dessous vous aidera à installer le modpack une fois [modrinth installé][modrinthappinstall].
Vous pouvez aussi utiliser [Prism][prism] selon votre préférence.

Comme décris dans la vidéo, vous pouvez installer des mods supplémentaires pour améliorer votre expérience de jeux selon vos gouts. Voici les mods conseillés actuellement (peuvent parfois ne pas être disponible dans la version de minecraft dans laquelle est le serveur):

## Fonctionnalités / mods
- **Skyboxify***: Permet d'avoir la texture du vrai ciel tel que les personnages sont censés le voir en RP
- **Remove reloading Screen***: Plus de freeze au changement de zone de Resource Pack
- **Simple Skin Swapper**: Permet de changer de skin sans quitter le jeu
- **Iris**: Mod pour les shaders
- **LambDynamicLights**: Pour les sources de lumières dynamiques, pour quand vous avez une torche en main par exemple
- **HB Tweaks - Names**: Mod permettant de voir le nom rp et le pseudo du compte minecraft en regardant quelqu'un
- **OGLinter**: Correction orthographique dans le chat
- **ETF/EMF**: Permet d'avoir des skins transparents (Exemple: bras manquant ect...) à la place de zones noires
- **Zoomify**: Mod de zoom
- **Sodium**, **MoreCulling**, **FerriteCore** et bien d'autres: Amélioration massive des performances
- Et pleins d'autres de petits ou gros mods rendant l'expérience vanilla plus confortable (meilleurs menus, corrections de bugs...)

*: Même si aucun mod n'est obligatoire, certains mods sont très fortements conseillés pour avoir l'experience RP complète et confortable
